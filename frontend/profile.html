Deployment Architecture Guide
CampusTrack separates client and server for cloud scalability:
  • Frontend (Vercel): Zero-maintenance static hosting with global CDN delivery.
  • Backend (Tomcat / Java Hosting): Deploy the generated campustrack.war to Tomcat 10, Render, Railway, or AWS.
  • Database (MySQL): Managed MySQL accessed via JDBC with connection pooling.
  • Lab Demo (JSP): Access traditional JSP pages directly at /jsp/index.jsp on the Tomcat server.
